# Release 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preparar o Open Presenter para a release 0.3.0 com atualização in-app, notas de versão para o público final, CI multi-plataforma e documentação de repositório.

**Architecture:** O updater oficial do Tauri (plugin `updater` + `process`) consulta o `latest.json` publicado nas GitHub Releases. A UI de novidades usa um catálogo local de notas amigáveis; a tela de atualizações usa o plugin e abre o changelog técnico no GitHub.

**Tech Stack:** Tauri v2, React 19, TypeScript, Zustand, Tailwind v4, GitHub Actions, tauri-action v1.

**Spec:** Solicitação de release do usuário + AGENTS.md.

## Global Constraints

- `main` é release; `develop` é integração.
- Versão 0.3.0 em `package.json`, `src-tauri/Cargo.toml` e `src-tauri/tauri.conf.json`.
- Licença MIT existente é mantida.
- Nenhuma chave privada de assinatura entra no repositório.
- `npm run typecheck` e `cargo check -p open-presenter` devem passar.
