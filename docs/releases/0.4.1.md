# Open Presenter 0.4.1

Correções de mídia e de monitores reportadas no Windows.

## Mídia (fundo do evento/tema)

- A **porta de mídia** é revalidada sempre que o estado das saídas muda. Antes
  ela era lida uma vez no boot; se o servidor subisse, parasse ou trocasse de
  porta depois, as imagens apontavam para o lugar errado.
- No desktop **sem servidor HTTP**, a mídia resolve para o protocolo `media://`
  em vez de apontar para uma porta morta.
- O caminho é codificado **por segmento** (sem escapar `/`), alinhado ao
  resolvedor da biblioteca de imagens.
- O `BackgroundRenderer` tenta `media://` quando o HTTP falha, evitando imagem
  quebrada.
- A janela do evento mostra **"Arquivo não encontrado"** com a URL resolvida
  quando o plano de fundo falha, para diagnóstico.

## Monitores (Windows)

- **Identidade estável** de monitor (nome + resolução) em vez do índice, que
  varia entre chamadas no Windows e fazia a atribuição se perder.
- As atribuições salvas (`monitorId`/`monitorName`) são **reconciliadas** com os
  monitores atuais ao carregar.
- O fallback escolhe um monitor **não-primário** (antes usava o índice 1, que no
  Windows costuma ser o principal).
- O **auto-activate** roda só no processo principal e **uma vez por sessão**:
  abrir a janela de Configuração de tela não reabre nem foca mais as saídas.
- A janela nativa existente **não recebe foco**; é reposicionada apenas se o
  monitor mudou.
- Nova saída prefere um monitor livre que não seja o principal.
