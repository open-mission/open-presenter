# Open Presenter 0.3.1

Identidade visual renovada e sistema de temas da interface baseado nos tokens
do shadcn/ui, com presets, edição de paletas e importação/exportação em JSON e
CSS.

## Identidade visual

- Novos assets SVG em `docs/brand/`: ícones claro, escuro, invertido,
  preenchido e monocromático, além dos wordmarks claro e escuro.
- Ícones do aplicativo regenerados para macOS, Windows, Linux, Android e iOS.
- Ícone monocromático dedicado à bandeja do macOS, com `icon_as_template` para
  acompanhar automaticamente o modo claro e escuro do sistema.
- Favicon SVG, PNG 32×32, ICO e Apple Touch Icon nas páginas web servidas pelo
  app.
- Wordmark oficial no README e marca aplicada no dock, preferências, atalhos,
  controle remoto e tela de informações.

## Tema da interface (shadcn/ui)

- Núcleo de tema em `src/core/theme/uiTheme.ts` com 31 tokens shadcn/ui para as
  paletas clara e escura, incluindo gráficos e barra lateral.
- Presets Open Presenter, Slate, Azul, Violeta, Verde, Âmbar, Rosa e Alto
  contraste.
- Editor em **Preferências → Aparência**, em uma seção recolhível, com:
  - seletor de paleta clara/escura;
  - edição de todos os tokens shadcn/ui;
  - ajuste de arredondamento (`--radius`);
  - prévia ao vivo com os componentes reais;
  - restauração do tema padrão.
- Persistência em `localStorage` na chave `open_presenter_ui_theme`.
- Aplicação via CSS custom properties no elemento raiz, integrada ao modo
  claro/escuro/sistema já existente.
- A prévia usa variáveis CSS isoladas no contêiner, então é possível editar a
  paleta escura mesmo com o aplicativo no modo claro.

## Importação e exportação

- JSON no formato `open-presenter-ui-theme`, com versão e paletas completas.
- CSS com blocos `:root` e `.dark`, reutilizável em projetos que usam os mesmos
  tokens.
- Importação parcial: tokens ausentes são completados com o tema padrão.
- Validação de valores CSS e de arredondamento antes da aplicação.
- Compatível com temas gerados por ferramentas do ecossistema shadcn/ui que
  usem os mesmos nomes de variáveis.

## Compatibilidade e migração

- Nenhuma migração de banco de dados é necessária; o tema da interface é
  armazenado apenas no `localStorage`.
- A chave `open_presenter_theme` (claro/escuro/sistema) continua válida.
- Os temas de projeção de público e palco permanecem inalterados e
  independentes da aparência do operador.
- O tema padrão é o preset Open Presenter; usuários podem restaurá-lo a
  qualquer momento no editor.

## Qualidade e manutenção

- Testes com `node:test` para normalização de cores, contraste, presets,
  serialização, importação/exportação e aplicação das variáveis CSS.
- Feature `image-png` habilitada no Tauri para carregar o PNG monocromático da
  bandeja.
- Versão atualizada para `0.3.1` em `package.json`, `package-lock.json`,
  `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock` e `src-tauri/tauri.conf.json`.
- Correção da versão exibida na janela de atalhos, que agora usa a versão real
  do app.
