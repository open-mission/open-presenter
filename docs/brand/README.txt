Open Presenter — SVG assets

All assets are editable vector SVGs and use simple paths, fills, and strokes.
No embedded raster images or external dependencies are used.

Files:
- open-presenter-icon-dark.svg: primary dark app tile with white mark
- open-presenter-icon-light.svg: light tile with dark mark
- open-presenter-icon-monochrome.svg: transparent background, outlined monochrome mark
- open-presenter-icon-filled.svg: solid dark screen mark
- open-presenter-icon-inverted.svg: white tile with dark mark
- open-presenter-app-icon.svg: softer light app icon variant
- open-presenter-wordmark.svg: transparent wordmark for light backgrounds
- open-presenter-wordmark-dark.svg: white wordmark for dark backgrounds

Colors:
- Ink: #111318
- Secondary gray: #6B7280
- Border gray: #D1D5DB
- White: #FFFFFF

You can recolor SVGs by changing the fill/stroke values. For use in React, the SVG files can be imported as assets or the paths can be copied into an inline SVG component.
