## Dependências Principais

- **Backend (Rust):**
  - `tauri` v2: Ponte nativa de SO, janelas e IPC.
  - `axum`: Servidor web assíncrono de alto desempenho embutido no app.
  - `rusqlite`: Banco de dados relacional embarcado local.
  - `tokio`: Runtime assíncrono para WebSocket e timers.
  - `serde` / `serde_json`: Serialização e deserialização bidirecional.
- **Frontend (Web):**
  - `react` 19 & `react-dom` 19.
  - `zustand` 5: Gerenciamento de estado rápido e desacoplado.
  - `tailwindcss` 4 + `@tailwindcss/vite`: Design system com variáveis CSS.
  - `radix-ui`: Primitivas acessíveis e robustas.
  - `lucide-react`: Ícones consistentes.
