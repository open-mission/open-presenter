---
title: Tabela de Atalhos de Teclado
description: Referência rápida de todos os atalhos de teclado para operadores ágeis.
---

Operadores que dominam os atalhos de teclado garantem um culto sem atrasos e sem distrações visuais.

---

## Navegação e Projeção ao Vivo

| Tecla / Atalho | Ação | Escopo |
| :--- | :--- | :--- |
| **`Enter`** | Projeta o slide selecionado para o ar | Apresentação |
| **`Espaço`** ou **`→`** | Avança para o próximo slide | Apresentação |
| **`Shift + Espaço`** ou **`←`** | Volta para o slide anterior | Apresentação |
| **`1, 2, 3... 9 + Enter`** | Pula diretamente para o slide de número digitado | Apresentação |
| **`B`** | **Blackout**: Escurece totalmente o telão com fade suave | Emergência |
| **`C`** | **Limpar Texto**: Oculta as letras mantendo o fundo | Apresentação |
| **`F`** | **Apresentar Fundo**: Projeta apenas o plano de fundo do tema | Apresentação |
| **`Esc`** | Cancela apresentação ativa / fecha janelas e modais | Geral |

---

## Janelas e Ferramentas

| Tecla / Atalho | Ação | Escopo |
| :--- | :--- | :--- |
| **`⌘ M`** / **`Ctrl + M`** | Abre o **Painel de Comunicação & Avisos** | Geral |
| **`⌘ ,`** / **`Ctrl + ,`** | Abre a janela de **Preferências & Configurações** | Geral |
| **`⌘ K`** / **`Ctrl + K`** | Busca rápida na Biblioteca de Músicas | Geral |
| **`⌘ ⇧ F`** / **`Ctrl + Shift + F`** | Busca músicas na Internet (Letras/Vagalume/LRCLIB) | Músicas |
| **`⌘ B`** / **`Ctrl + B`** | Alterna para a visão da **Bíblia Sagrada** | Bíblia |
| **`⌘ Enter`** | Envia o aviso digitado no Painel de Comunicação | Avisos |

---

## Editor de Temas

| Tecla / Atalho | Ação | Escopo |
| :--- | :--- | :--- |
| **`⌘ D`** / **`Ctrl + D`** | Duplica a seleção (a cópia fica selecionada) | Editor de Temas |
| **`Delete`** / **`Backspace`** | Apaga a seleção | Editor de Temas |
| **`⌘ G`** / **`Ctrl + G`** | Agrupa a seleção | Editor de Temas |
| **`⌘ ⇧ G`** / **`Ctrl + Shift + G`** | Desagrupa a seleção | Editor de Temas |
| **`⌘ A`** / **`Ctrl + A`** | Seleciona todos os elementos da página ativa | Editor de Temas |
| **`⌘ Z`** / **`Ctrl + Z`** | Desfaz | Editor de Temas |
| **`⌘ ⇧ Z`** / **`Ctrl + Y`** | Refaz | Editor de Temas |
| **`⌘ S`** / **`Ctrl + S`** | Salva o tema | Editor de Temas |
| **`Shift` + clique** | Adiciona ou remove o elemento da seleção | Editor de Temas |
| **`⌘` / `Ctrl` + clique** | Entra no grupo e seleciona o item | Editor de Temas |
| **`Shift` durante o gesto** | Mantém a proporção ao redimensionar e trava a rotação em 15° | Editor de Temas |
